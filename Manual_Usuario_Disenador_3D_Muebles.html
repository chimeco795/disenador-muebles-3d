Diseñador 3D de Muebles

Manual de usuario

Versión del documento: 1.0 borrador
Objetivo: explicar de forma práctica cómo diseñar, preparar y documentar un mueble dentro del sistema.

Nota: este manual está construido con base en las funciones definidas y desarrolladas durante las fases del proyecto. Algunos nombres de botones o detalles visuales pueden variar ligeramente según la versión actual del código.

1. Introducción

El Diseñador 3D de Muebles está pensado para crear muebles de manera visual, sencilla y orientada a fabricación.

La filosofía del sistema es:

Construir como LEGO, no trabajar como CAD.

El usuario trabaja con piezas reales de carpintería —tablas, listones, MDF, triplay y otros tableros— y las coloca, mueve, gira, corta y une dentro de un espacio 3D.

El sistema conserva las medidas reales en milímetros, pero representa las piezas con una escala visual adecuada para trabajar cómodamente en pantalla.

Además del diseño, el sistema puede preparar información de fabricación:

  • piezas necesarias;
  • materiales originales;
  • sobrantes;
  • planes de corte;
  • optimización de material;
  • perforaciones;
  • uniones;
  • reporte para taller o aserradero.

2. Flujo general de trabajo

El flujo recomendado es:

  1. Crear o abrir un proyecto.
  2. Agregar piezas desde el catálogo o desde una plantilla.
  3. Construir el mueble en la vista Diseño.
  4. Ajustar posiciones, giros y Snap.
  5. Realizar cortes.
  6. Agregar perforaciones, cortes especiales o uniones cuando sea necesario.
  7. Revisar materiales y sobrantes.
  8. Entrar a Fabricación.
  9. Revisar u optimizar el plan de corte.
  10. Generar el reporte para taller/aserradero.
  11. Guardar el proyecto para continuar después.

3. Interfaz principal

3.1 Área de trabajo 3D

Es la zona central donde se construye el mueble.

Aquí se pueden:

  • seleccionar piezas;
  • mover;
  • girar;
  • hacer Snap;
  • cortar;
  • medir;
  • crear perforaciones;
  • crear uniones;
  • revisar cotas.

La cámara puede girar alrededor del proyecto para trabajar desde cualquier ángulo.

3.2 Catálogo

El catálogo contiene piezas y materiales disponibles para agregar al proyecto.

Puede incluir categorías como:

  • tablas;
  • listones;
  • MDF;
  • triplay;
  • melamina;
  • OSB;
  • aglomerado;
  • plantillas de muebles.

El catálogo debe mantenerse organizado mediante categorías, filtros o búsqueda para evitar saturar la interfaz.

3.3 Paneles de propiedades

Los paneles muestran información y opciones relacionadas con la pieza seleccionada.

Entre ellas pueden aparecer:

  • dimensiones;
  • posición;
  • rotación;
  • material;
  • estado;
  • operaciones;
  • uniones;
  • datos de fabricación.

3.4 Diseño y Fabricación

El sistema separa dos contextos principales.

Diseño

Se utiliza para construir el mueble y trabajar directamente con sus piezas.

Fabricación

Se utiliza para revisar:

  • lista de piezas;
  • materiales;
  • sobrantes;
  • plan de cortes;
  • optimización;
  • reporte de fabricación.

Esta separación mantiene limpia la experiencia del editor 3D.

4. Crear, abrir y guardar proyectos

4.1 Proyecto nuevo

Utiliza Nuevo para comenzar desde cero.

Antes de reemplazar un proyecto existente, guarda el trabajo si deseas conservarlo.

4.2 Guardar proyecto

El sistema puede guardar el proyecto en un archivo propio, por ejemplo:

MiMesa.crj

Internamente puede estar basado en JSON, pero para el usuario funciona como un archivo normal de proyecto.

El archivo debe conservar, entre otros datos:

  • piezas;
  • dimensiones;
  • posiciones;
  • rotaciones;
  • materiales;
  • cortes;
  • sobrantes;
  • perforaciones;
  • uniones;
  • configuración;
  • información de fabricación.

4.3 Abrir proyecto

Utiliza Abrir y selecciona un archivo de proyecto compatible.

El sistema reconstruye el estado guardado para poder continuar trabajando.

4.4 Guardado local

Además del archivo manual, algunas versiones pueden conservar automáticamente el estado en almacenamiento local del navegador.

El archivo de proyecto es recomendable cuando:

  • se desea respaldar el trabajo;
  • se quiere continuar en otro equipo;
  • se desea conservar diferentes versiones del mismo mueble.

5. Agregar piezas y materiales

5.1 Desde el catálogo

Selecciona una pieza o arrástrala desde el catálogo hacia el área 3D.

La pieza se agrega utilizando sus dimensiones reales y su material asociado.

5.2 Tipos de material

Tablas

Piezas largas de madera dimensional.

Ejemplo: 3000 × 100 × 18 mm

Listones

Piezas estrechas, normalmente usadas para estructuras, bastidores o refuerzos.

MDF / Triplay / Melamina / OSB / Aglomerado

Materiales tipo hoja o tablero.

Ejemplo: 2440 × 1220 × 18 mm

5.3 Dimensiones configurables

Las medidas del catálogo funcionan como punto de partida. Cuando la interfaz lo permita, pueden ajustarse para representar el material real que se utilizará.

6. Plantillas

Las plantillas permiten comenzar rápidamente con estructuras comunes sin convertir el sistema en un catálogo rígido de muebles prefabricados.

Pueden existir plantillas como:

  • caja cerrada;
  • caja abierta;
  • repisa;
  • estantería;
  • mesa;
  • banco;
  • cajonera;
  • escalera;
  • marco.

6.1 Crear desde plantilla

Una plantilla solicita únicamente los parámetros necesarios.

Ejemplo para una mesa:

  • ancho;
  • fondo;
  • alto;
  • material.

Después genera piezas normales del sistema. Estas piezas pueden moverse, cortarse, eliminarse, modificarse y unirse como cualquier otra.

La plantilla acelera el inicio, pero no bloquea el diseño.

7. Seleccionar, mover y organizar piezas

7.1 Seleccionar

Haz clic sobre una pieza para seleccionarla.

La selección puede mostrar:

  • resaltado;
  • dimensiones;
  • controles de movimiento;
  • controles de rotación;
  • información en el panel de propiedades.

7.2 Selección múltiple

Cuando esté disponible, utiliza Shift + clic para añadir o retirar piezas de una selección múltiple.

Esto permite mover varias piezas al mismo tiempo.

7.3 Agrupar temporalmente

Las piezas seleccionadas pueden agruparse temporalmente para facilitar el movimiento de un conjunto.

El agrupamiento no debe convertirlas en una sola pieza física; únicamente facilita su manipulación.

7.4 Movimiento libre

Arrastra la pieza hacia la posición deseada sobre los ejes X, Y y Z.

7.5 Ajuste fino

Cuando esté disponible:

  • Flechas: movimiento pequeño.
  • Shift + Flechas: movimiento mayor.

Esta función resulta útil cuando una pieza ya está prácticamente colocada.

8. Girar piezas

Las piezas pueden rotarse para adoptar la orientación necesaria.

El sistema puede sugerir ángulos comunes:

  • 0°;
  • 15°;
  • 30°;
  • 45°;
  • 60°;
  • 90°.

La rotación sigue permitiendo valores libres cuando es necesario.

8.1 Snap angular

Al acercarse a un ángulo común puede aparecer una guía visual y una ligera atracción magnética.

El objetivo es facilitar ángulos frecuentes sin bloquear la libertad del usuario.

9. Cámara y vistas

La cámara permite observar el proyecto desde diferentes posiciones.

Puede incluir accesos rápidos como:

  • frontal;
  • posterior;
  • izquierda;
  • derecha;
  • superior;
  • isométrica.

9.1 Enfocar una pieza

Cuando esté disponible, haz doble clic sobre una pieza para centrar la cámara en ella.

9.2 Ajustar todo

La opción Ajustar todo encuadra el proyecto completo.

Es útil si el mueble sale del área visible o la cámara queda demasiado cerca.

10. Snap entre piezas

El Snap ayuda a colocar piezas correctamente sin tener que introducir coordenadas manualmente.

10.1 Snap cara a cara

Al acercar una cara de una pieza a otra, el sistema detecta candidatos compatibles.

Antes de completar el Snap puede resaltarse:

  • la cara de la pieza móvil;
  • la cara destino;
  • una guía visual.

10.2 Snap desde el punto de agarre

El sistema puede considerar desde qué zona se tomó la pieza.

Esto permite, por ejemplo, tomar una tabla desde un extremo y hacer Snap usando ese extremo en lugar de depender exclusivamente del centro geométrico.

10.3 Alineación inteligente

Después de detectar las caras, el sistema intenta modificar el menor número posible de coordenadas.

La idea es:

hacer contacto sin mover innecesariamente la pieza en otros ejes.

Según la versión pueden existir opciones como:

  • centro;
  • borde inicial;
  • borde final;
  • libre.

10.4 Guías

Durante el movimiento pueden aparecer guías para:

  • centros;
  • bordes;
  • misma altura;
  • misma profundidad.

Las guías son temporales y desaparecen al terminar la operación.

11. Copiar, duplicar y repetir acciones

11.1 Copiar / duplicar

Utiliza Copiar o Duplicar para crear otra pieza con las mismas características.

Normalmente se conserva:

  • material;
  • dimensiones;
  • orientación;
  • propiedades básicas.

Después la copia puede moverse de forma independiente.

11.2 Repetir última acción

La función Repetir última acción permite reutilizar una operación reciente sobre otra pieza compatible.

Puede utilizarse con acciones como:

  • duplicar;
  • girar;
  • mover;
  • cortar.

Ejemplo:

  1. Girar una pieza 90°.
  2. Seleccionar otra.
  3. Ejecutar Repetir última acción.
  4. La segunda pieza recibe el mismo giro.

Para cortes, el sistema puede recordar dirección, medida y tipo de corte.

Si la acción no es compatible con la pieza seleccionada, no debe aplicarse de forma incorrecta.

12. Bloquear, ocultar y eliminar

12.1 Bloquear

Una pieza bloqueada permanece en su posición y evita movimientos accidentales.

12.2 Ocultar

Permite retirar temporalmente una pieza de la vista sin eliminarla del proyecto.

12.3 Eliminar

Elimina la pieza del diseño. Cuando corresponda, la acción puede recuperarse mediante Undo.

13. Undo y Redo

El sistema mantiene historial de operaciones importantes.

Undo

Deshace la última acción.

Redo

Vuelve a aplicar una acción deshecha.

El historial debe contemplar operaciones como movimiento, rotación, duplicación, corte y otras operaciones compatibles.

14. Cortar piezas

La herramienta Cortar divide una pieza en dos partes reales dentro del proyecto.

La interacción principal es visual.

14.1 Línea de corte

Al activar la herramienta aparece una línea sobre la pieza.

La línea puede desplazarse con el mouse y mientras se mueve se muestran las medidas resultantes.

Ejemplo:

720 mm | 2280 mm

14.2 Medida exacta

Aunque el corte sea visual, puede introducirse una medida exacta cuando sea necesario.

El sistema puede aplicar una ligera ayuda a medidas redondas.

14.3 Confirmar o cancelar

Acciones habituales:

  • Confirmar.
  • Cancelar.
  • Enter: confirmar.
  • Esc: cancelar.

15. Corte de tablas y listones

Las tablas pueden cortarse en más de una dirección.

15.1 Corte transversal

Divide principalmente la longitud.

Ejemplo: 3000 mm → 720 mm + 2280 mm

15.2 Corte longitudinal

Divide el ancho de la tabla.

Ejemplo: 100 mm → 40 mm + 60 mm

Las piezas resultantes siguen siendo piezas normales del proyecto.

16. Corte de MDF y triplay

Los tableros pueden cortarse sobre sus dos dimensiones principales.

Al iniciar el corte se puede elegir o inferir la orientación:

  • horizontal;
  • vertical.

La línea atraviesa completamente la pieza.

Después del corte, ambas partes pueden volver a cortarse.

17. Trazabilidad de cortes

Cada pieza cortada conserva su relación con el material de origen.

Ejemplo:

TABLA-001
├── A1
└── A2
    ├── A3
    └── A4

Esta relación permite saber de qué material original proviene cada pieza.

La trazabilidad es importante para:

  • sobrantes;
  • fabricación;
  • optimización;
  • reportes.

18. Colores de piezas cortadas

Los materiales originales utilizan colores más fuertes.

Las piezas resultantes de un corte utilizan una versión más clara del mismo color.

El objetivo es distinguir visualmente material original y material ya procesado sin que los colores cortados pierdan su identidad.

19. Sobrantes

Después de un corte, ninguna de las dos partes se considera automáticamente desperdicio.

Un sobrante puede:

  • seleccionarse;
  • moverse;
  • reutilizarse;
  • cortarse de nuevo;
  • incorporarse al mueble.

Esto permite aprovechar material real de forma más eficiente.

20. Materiales del proyecto

El panel de materiales puede mostrar información como:

TABLA-001
Pino — 3000 × 100 × 18
Utilizado: 1170 mm
Disponible: 1830 mm

Para hojas o tableros puede indicar si están sin cortar, parcialmente utilizados o disponibles como sobrante.

21. IDs de piezas

Las piezas pueden recibir identificadores legibles, por ejemplo:

  • A1;
  • A2;
  • A3;
  • B1;
  • B2.

Estos IDs se utilizan de forma consistente en:

  • Diseño;
  • Fabricación;
  • Plan optimizado;
  • Reporte.

Esto permite identificar físicamente cada pieza en el taller.

22. Perforaciones

La herramienta Perforar agrega una operación de perforación sobre una cara.

Flujo recomendado:

  1. Seleccionar la pieza.
  2. Elegir Perforar.
  3. Hacer clic sobre una cara.
  4. Colocar visualmente la perforación.
  5. Definir diámetro.
  6. Definir profundidad si aplica.
  7. Confirmar.

22.1 Presets

Pueden existir medidas rápidas como:

  • Ø5;
  • Ø8;
  • Ø10;
  • Ø35;
  • personalizado.

22.2 Usos típicos

  • pasacables;
  • tarugos;
  • tornillos;
  • bisagras de cazoleta.

La perforación se conserva como información de fabricación.

23. Cortes angulares

La herramienta de corte puede admitir corte recto y corte angular.

Puede ofrecer ángulos frecuentes como 15°, 30°, 45° y 60°, además de valores personalizados.

Antes de confirmar debe mostrarse una previsualización.

24. Curvas simples

El sistema puede manejar operaciones sencillas predefinidas como:

  • esquina redondeada;
  • arco;
  • semicírculo;
  • círculo/agujero.

El objetivo es cubrir necesidades comunes sin convertirse en un editor CAD libre.

25. Uniones entre piezas

Las uniones permiten indicar cómo se ensamblarán dos piezas.

Tipos posibles:

  • sin especificar;
  • tornillos;
  • tarugos;
  • pocket hole;
  • espiga;
  • otro.

25.1 Crear una unión

El flujo visual ideal es:

  1. Elegir Unir.
  2. Seleccionar una cara de la primera pieza.
  3. Seleccionar o arrastrar hacia la cara destino.
  4. Confirmar la unión.
  5. Elegir el tipo de ensamble.

Las caras pueden resaltarse durante el proceso.

25.2 Propiedades de unión

Según el tipo pueden existir datos como:

  • cantidad;
  • diámetro;
  • longitud;
  • separación;
  • posición;
  • notas.

25.3 Unión en el 3D

La unión puede representarse mediante una marca visual discreta.

No es necesario modelar cada tornillo o tarugo físicamente.

26. Medición y cotas

26.1 Medición

La herramienta Medir permite obtener una distancia temporal.

Flujo:

  1. Activar Medir.
  2. Seleccionar primer punto o cara.
  3. Seleccionar segundo punto o cara.
  4. Leer la distancia en mm.

La medición no modifica el proyecto.

26.2 Cotas

Al seleccionar una pieza, pueden mostrarse sus dimensiones de forma discreta.

Ejemplo: 1200 × 400 × 18 mm

Las cotas pueden ocultarse para mantener limpia la escena.

27. Vista Fabricación

La vista Fabricación transforma el diseño en información práctica para taller.

Puede mostrar:

  • resumen del proyecto;
  • lista de piezas;
  • materiales;
  • plan actual;
  • plan optimizado;
  • sobrantes;
  • kerf;
  • reporte.

28. Lista de piezas

La lista de piezas puede tener una estructura como:

ID Material Dimensiones Origen
A1 Pino 720 × 100 × 18 TABLA-001
A2 Pino 450 × 100 × 18 TABLA-001
B1 MDF 800 × 500 × 18 HOJA-001

Los IDs deben coincidir con los mostrados en el diseño.

29. Plan de tablas

Para cada tabla se muestra cómo se obtuvieron o deben obtenerse las piezas.

Ejemplo:

TABLA #1 — 3000 mm

| A1 720 | A2 450 | A3 800 | SOBRANTE 1030 |

La representación puede mantener proporciones aproximadas para facilitar su lectura.

30. Plan de hojas

Para MDF, triplay y materiales similares se muestra una representación 2D.

Ejemplo:

┌──────────────────────────────┐
│ A1               │ A2       │
│ 800 × 500        │ 600×500  │
├──────────────────┴───────────┤
│         SOBRANTE             │
└──────────────────────────────┘

La vista muestra piezas, IDs, dimensiones, líneas de corte y sobrantes.

31. Kerf

El kerf representa el ancho de material perdido por el disco de la sierra.

Ejemplo: Kerf = 3 mm

Esta pérdida debe considerarse en los cálculos del plan de corte y de optimización.

32. Plan actual y plan optimizado

Fabricación puede distinguir:

Plan actual

Representa la forma en que las piezas fueron cortadas o distribuidas durante el diseño.

Plan optimizado

Es una propuesta automática para reducir número de tablas, número de hojas y desperdicio.

La optimización no modifica el modelo 3D.

33. Optimización de tablas

Para tablas y listones se utiliza una optimización 1D basada principalmente en longitud.

El sistema distribuye piezas dentro de materiales comerciales considerando el kerf.

El objetivo es reducir el número de materiales utilizados.

34. Optimización de hojas

Para MDF/triplay se utiliza optimización 2D.

El sistema intenta distribuir rectángulos dentro de una o varias hojas.

Puede probar rotaciones de 90° cuando están permitidas.

34.1 Rotación

Puede existir una opción:

Permitir rotación de piezas: Sí / No

Esto ayuda a aprovechar mejor la hoja.

La dirección de veta puede limitar estas rotaciones cuando esa regla esté configurada.

35. Reutilización de sobrantes

El optimizador puede considerar sobrantes existentes antes de solicitar material nuevo.

Debe distinguir:

  • material nuevo;
  • sobrante reutilizado.

Un sobrante sólo debe utilizarse cuando realmente puede contener la pieza requerida.

36. Plan desactualizado

Si después de optimizar se modifica una pieza, una medida, un material o el kerf, el sistema puede marcar el plan como desactualizado.

En ese caso debe ejecutarse nuevamente Optimizar material antes de usarlo como referencia definitiva.

37. Lista de compra

A partir del plan optimizado puede generarse una lista como:

3 × Pino 3000 × 100 × 18 mm
2 × MDF 2440 × 1220 × 18 mm

Puede diferenciar entre material nuevo y sobrantes reutilizados.

38. Orden de cortes

Para tablas puede mostrarse un orden práctico.

Ejemplo:

  1. Cortar A1 — 720 mm.
  2. Cortar A3 — 450 mm.
  3. Cortar A7 — 800 mm.
  4. Conservar sobrante.

El kerf debe incluirse en el cálculo correspondiente.

39. Reporte de fabricación

Desde Fabricación puede generarse un reporte pensado para taller o aserradero.

El reporte no debe mostrar información interna del software y debe ser comprensible para alguien que no utiliza la aplicación.

39.1 Contenido

Puede incluir:

Proyecto

  • nombre;
  • fecha;
  • resumen.

Lista de compra

Material, medidas comerciales y cantidad.

Lista de piezas

ID, material, dimensiones y cantidad.

Plan de tablas

Distribución de piezas y sobrantes.

Plan de hojas

Diagramas 2D con IDs y medidas.

Operaciones especiales

  • cortes angulares;
  • perforaciones;
  • curvas;
  • uniones.

39.2 Cerrar reporte

La vista del reporte debe comportarse como una pantalla convencional:

  • X: cerrar;
  • Esc: cerrar;
  • regresar a Fabricación.

39.3 Exportar

Puede incluir:

  • Exportar PDF;
  • Imprimir.

El documento utiliza milímetros y evita datos como UUID, JSON o identificadores internos.

40. Menú contextual

Cuando esté disponible, el clic derecho sobre una pieza puede mostrar acciones frecuentes como:

  • duplicar;
  • cortar;
  • unir;
  • ocultar;
  • eliminar.

Esto reduce desplazamientos por la interfaz.

41. Buenas prácticas de diseño

41.1 Construir de lo general a lo particular

Primero coloca las piezas principales. Después agrega divisiones, cortes, perforaciones y uniones.

41.2 Bloquear piezas terminadas

Si una pieza ya está correctamente colocada, bloquéala para evitar movimientos accidentales.

41.3 Utilizar Snap antes de ajustes manuales

Acerca primero la pieza y utiliza Snap. Después realiza ajustes pequeños si son necesarios.

41.4 Mantener sobrantes

No elimines inmediatamente las piezas sobrantes. Pueden utilizarse posteriormente y mejorar la optimización.

41.5 Optimizar al final

No es necesario ejecutar optimización después de cada cambio. Primero termina el diseño y luego utiliza Optimizar material.

42. Ejemplo rápido: crear una mesa

  1. Crear un proyecto nuevo.
  2. Agregar una cubierta o utilizar la plantilla Mesa.
  3. Agregar o revisar las cuatro patas.
  4. Mover y girar las patas.
  5. Utilizar Snap cara a cara para colocarlas debajo de la cubierta.
  6. Revisar dimensiones con cotas o Medir.
  7. Crear las uniones necesarias.
  8. Cambiar a Fabricación.
  9. Revisar piezas, materiales y sobrantes.
  10. Ejecutar Optimizar material.
  11. Generar el reporte para taller.
  12. Guardar el proyecto.

43. Ejemplo rápido: crear una repisa

  1. Crear proyecto.
  2. Agregar dos laterales.
  3. Agregar repisas horizontales.
  4. Utilizar Snap para posicionarlas.
  5. Duplicar una repisa tantas veces como sea necesario.
  6. Utilizar Repetir última acción cuando resulte útil.
  7. Crear perforaciones o uniones.
  8. Revisar Fabricación.
  9. Optimizar material.
  10. Generar reporte.

44. Ejemplo rápido: crear una cajonera

  1. Utilizar la plantilla de cajonera si está disponible.
  2. Definir ancho, alto, fondo y material.
  3. Ajustar las piezas generadas.
  4. Revisar separaciones.
  5. Crear cajones.
  6. Agregar perforaciones y uniones necesarias.
  7. Revisar cortes de MDF/triplay.
  8. Optimizar hojas.
  9. Generar reporte.

45. Solución de problemas

La pieza hace Snap en una posición inesperada

Prueba:

  1. acercar la cara correcta;
  2. tomar la pieza desde el borde/extremo que deseas unir;
  3. revisar la previsualización;
  4. cambiar el tipo de alineación;
  5. realizar un ajuste fino después del Snap.

Perdí el mueble de vista

Usa Ajustar todo o una vista rápida.

Corté una pieza por error

Utiliza Undo.

El plan optimizado no coincide con el proyecto

Verifica si aparece como desactualizado y vuelve a ejecutar la optimización.

No quiero perder un sobrante

No lo elimines. Déjalo disponible para que pueda reutilizarse.

El reporte no refleja el último cambio

Actualiza el plan de fabricación u optimización antes de generar nuevamente el reporte.

46. Atajos y acciones rápidas

Los atajos exactos pueden depender de la versión.

47. Conceptos importantes

Material original

Tabla u hoja comercial de la que provienen una o más piezas.

Pieza

Elemento individual utilizado para construir el mueble.

Sobrante

Parte no utilizada de un material que sigue siendo aprovechable.

Source material

Referencia interna que vincula una pieza con su material original.

Kerf

Material perdido por el espesor del disco de corte.

Snap

Ayuda automática para hacer coincidir caras, bordes o alineaciones.

Plan actual

Distribución derivada del trabajo realizado durante el diseño.

Plan optimizado

Propuesta calculada para reducir material y desperdicio.

48. Filosofía del sistema

El objetivo no es sustituir un CAD profesional ni generar mecanizado CNC completo.

El sistema busca que una persona pueda:

imaginar un mueble, construirlo visualmente con piezas reales, entender qué material necesita y llevar un plan claro al taller.

Por esa razón la interfaz prioriza:

  • simplicidad;
  • interacción visual;
  • medidas reales;
  • pocas ventanas;
  • feedback inmediato;
  • funciones de carpintería concretas;
  • facilidad de fabricación.

49. Integrar este manual dentro de la aplicación

La recomendación es mantener el archivo Markdown como fuente principal del manual.

Estructura sugerida:

/docs
  manual-usuario.md

Y mostrarlo desde una opción como:

Ayuda → Manual de usuario

Ventajas de Markdown:

  • fácil de mantener;
  • versionable en Git;
  • puede actualizarse junto con el código;
  • puede convertirse a HTML/PDF;
  • puede mostrarse directamente dentro de React.

Una estructura posible dentro de la aplicación:

Ayuda
├── Inicio rápido
├── Diseño
├── Piezas y materiales
├── Snap
├── Cortes
├── Perforaciones
├── Uniones
├── Fabricación

└── Atajos

La versión web puede generarse desde el mismo Markdown para evitar mantener dos manuales diferentes.
